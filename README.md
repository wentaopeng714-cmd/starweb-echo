# 星网回声 · Starweb Echo

An original interactive Canvas and WebAudio artwork. No dependencies or API keys required.

- Tap to pluck; tap steadily to sustain rhythmic echoes.
- Drag slowly to stretch, swipe quickly to sever silk.
- Carry fallen stars back into the web to reseed them.
- Hold intact silk to release stars; hold near a tear to stitch it.
- Drag the white weaver to guide repairs. It also repairs continuously while you play.
- Use the note button for sound and the circular arrow to reset.

Open `index.html` locally, or use the repository's GitHub Pages deployment.
